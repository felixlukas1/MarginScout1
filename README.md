# MarginScout

Eine KI-gestützte Web-App zur Analyse profitabler Produkte.

## Roadmap

### Version 1
- Dashboard
- Produktsuche
- Gewinnrechner

### Version 2
- eBay
- Amazon

### Version 3
- Kaufland
- Otto
- AliExpress

## Ziel

Eine Plattform, die automatisch erkennt, welche Produkte sich mit Gewinn weiterverkaufen lassen.
