# MarginScout

## Ziel

Eine KI-gestützte Web-App, die profitable Produkte für den Weiterverkauf findet.

## Funktionen

- Dashboard
- Produktsuche
- Gewinnrechner
- KI-Bewertung
- Amazon
- eBay
- Kaufland
- Otto
- AliExpress
- Preisverlauf
- Preisalarm
- Favoriten

## Version 1

- Dashboard
- Gewinnrechner
- Produktsuche

## Version 2

- Amazon API
- eBay API

## Version 3

- Weitere Marktplätze
- KI-Empfehlungen
